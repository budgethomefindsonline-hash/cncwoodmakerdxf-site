4. Экспорт для LightBurn

Масштаб 1:1, единицы — миллиметры. Слои: ENGRAVE (чёрный), CUT_INNER (красный), CUT_OUTER (синий).
  1. ENGRAVE — гравировка
  2. CUT_INNER — внутренние стыки
  3. CUT_OUTER — внешний контур (последним, чтобы лист не сдвинулся)

5. Проверка

Шесть сценариев на текущих параметрах: PNG-логотип → вектор, JPG-фото → полутона, пазл без изображения, SVG в углах → обрезка по скруглённому контуру, блокировка экспорта и неизменность ZIP, SVG с огромным viewBox → точная матрица. Проверяются размеры и то, что каждый стык есть в файле ровно один раз.
